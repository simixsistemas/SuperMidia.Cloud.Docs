# Editor de layouts

O **Editor** cria e altera os layouts usados na [Geração de cartazes](Geracao.md).

Acesse pelo menu **Cartazes/Encartes → Novo → Criar layout** (ou **Criar Layout V2**), ou pelo botão **Editar layout** na tela de Geração.

## Conceitos

- **Layout**: o modelo do cartaz, com fundo, textos, imagem do produto e preço.
- **Formato**: o tamanho de saída (A4, A3, story, TV...). Um layout pode ter vários formatos.
- **Rascunho e publicação**: o que você salva fica em rascunho. Só depois de **publicar** as alterações ficam disponíveis para todos na Geração.

## Passo a passo

1. Abra um layout existente ou crie um novo.
2. Clique no nome no topo para renomear o layout.
3. Adicione e posicione os elementos (textos, imagens, preço, código de barras etc.).
4. Use **Salvar** com frequência.
5. Quando estiver pronto, clique em **Publicar** (ícone de nuvem) para liberar o layout na Geração.

## Publicações

No menu **⋮** ao lado de Publicar:

- **Histórico de publicações**: veja as versões já publicadas;
- **Reverter publicação**: volta para a versão publicada anterior.

## Dicas

- Teste o layout na Geração com a opção **Demo** de produtos antes de publicar.
- Layouts padrão não podem ser editados diretamente: crie um layout a partir deles.
